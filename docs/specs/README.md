# Specs

One file per feature, numbered, written before code. Template:

```
# 003: Place order

## Context
Who needs this and why. Link to domain terms.

## Acceptance criteria
- AC1: Given … when … then …   → test name: placeOrder_withLoadingMetres_emitsOrderPlaced
- AC2: …

## Out of scope
What this spec deliberately does not do.

## Open questions
```

Acceptance criteria become test names. If a criterion cannot be turned into a test, it is not a criterion yet.
